# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, give constructive feedback, and keep discussion
about the work. Harassment of any kind is not tolerated.

Report unacceptable behaviour to the maintainers privately through a
[GitHub security advisory](https://github.com/SpandanNagale/Task-Agent/security/advisories/new)
or by contacting a maintainer directly. Reports are handled confidentially.
